# Nestly agent instructions

## Project bootstrap doctrine

Before creating a new project, application, service, worker, agent system, MCP server, mobile client, data workload, or performing a major rescaffold, read:

- `docs/quick-start-blueprint-library.md`

Do not start from a blank scaffold when a suitable canonical blueprint exists. Select the smallest suitable blueprint, compose blueprints when necessary, verify the upstream source is current and appropriately licensed, and record the chosen source plus important deviations.

Treat the agent harness, tests, acceptance criteria, and verification evidence as part of the foundation.

For ordinary edits that do not create or substantially re-architect a project, this bootstrap check is not required.

Existing Nestly runtime capability, authorization, tenant-isolation, receipt, and verification rules in `docs/contract.md` remain authoritative.
